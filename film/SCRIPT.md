# 「一根线」 — Deep Research 产品宣发片脚本

- 片长：~33.4s · 1920×1080 · 中文 · 无对白（音乐后补）
- 中心意象：**引用之线**——首页「证据」段里那根从句子上引到原文的 accent 蓝线，
  就是这部片子的主角。它从问题里抽出来，串起每个板块，最后绕成 logo。
- 制作方法：onetake 管线，单 HTML composition + `lib/motion.js`，
  真实快门模糊渲染；全部 UI 按产品设计体系复刻（不录屏）。
- 参考解构（tessel launch 33s）：静场 18% / 低速 39%，切点只在 burst，
  14 个运镜 t80≈0.66，带 smear 0.56 快门模糊。本片的节奏目标对齐它。

## 叙事逻辑

一句话：「一个问题 → 一根线 → 一份每句都有来处的报告」。

情绪弧：安静的提问 → 线出现（第一次 whip）→ 检索 + 过闸的快节奏劳动 →
**全场静止的审批**（人在回路，情绪低点，本片最重要的一个 beat）→
三线并行写作的爆发 → 一处朱批的诚实 → 拉远看整份被线装订的报告 → 账单 → 收尾。

品牌 token（取自首页/产品）：ground `#FBFAF9`，card `#FFF`，ink `rgba(0,0,0,.9)`，
mute `rgba(0,0,0,.6)`，line `rgba(0,0,0,.08)`，accent `#2E50C8`（线/可点），
live `#3E8F4F`（在跑），seal `#C4412F`（存疑/朱批），五色来源条
`#3E8F4F #2E50C8 #B8B4AC #7B5EA7 #C28A2B`。
字形：衬线 display（Songti 系）+ 无衬线正文（Heiti/PingFang 系）+ mono（Geist Mono）。
签名小物：刻度尺 hairline、88px 纸面网格。

## 线头运动学规则（v2 商定，所有板块布局迁就它）

1. **线只做板块间的转场，不在板块内部表演**。板块内部（框架级联、文字写作、
   引文落扣）让元素自己动；没有"每行文字跟一根线"。
2. **停靠语义**：线头在每个板块的**左上角状态点**降落停靠（审批面板 header、
   报告页左上角），像插头插进板块；离开后这个点就是它的身份。
3. **转场近直**：板块间飞行走大半径单弧，不折、不绕；衔接距离要近——
   库堆挪到闸门出口旁，报告页与审批面板同高，消灭"一下子上一下子下"。
4. **尾巴**：彗星式渐变尾（~380u，alpha→0），静止即收没；**遇急转弯（>50°）
   尾巴当场截断**，不留 ∧/V 形折角残渣。
5. **无镜头震动**（全部 shake 已删）；指针走直线直奔按钮。
6. **收尾线头隐身**：logo 画完线头即淡出，不留蓝点。

## 节奏自检（对齐参考片）

- 前两板块（提问/出线/检索雨/过闸）整体放慢：打字 ~10 字/s、雨间隔 0.11s、
  过闸 0.19s/张；总长从 ~29.6s 拉到 ~33.4s ✓
- 静场：审批 ~1.5s 全场静止 + 收尾 dead still ~3s+ ✓
- burst：检索雨、写作落钉；审批静场夹在中段 ✓

## 衔接自检（每边界都有存活物）

光标→线 · 线→卡片流 · 卡片流→库堆 · 库堆→线抬头升挂 · 线头停靠（框架自己展开）→
点击→线头离站飞到报告角点 · 红扣→镜头去审查 · 拉远显整页 ·
**页与引文整体淡出、线头直飞画 logo**。**全程无替换式转场。**
